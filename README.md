# Authentication Backend

## Features

* Article CRUD
* User Registration
* User Login
* Password Hashing
* JWT Authentication
* JWT Token Generation
* Zod Validation
* Error Handling

## Upcoming

* Forgot Password
* Email Verification
* Password Change
* OTP
* Two-Factor Authentication (2FA)

## Tech Stack

* Node.js
* Express
* TypeScript
* Prisma
* PostgreSQL
* Zod
* bcrypt
* JWT

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Production

```bash
npm start
```
